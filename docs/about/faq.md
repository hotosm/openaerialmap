# FAQ

## What is OpenAerialMap?

OpenAerialMap (OAM) is an open service for finding, sharing, and using openly
licensed satellite and drone imagery.

## Can I use OAM imagery for free?

OAM is free to access. Each image has its own license, so check that license for
any attribution or reuse requirements.

## Can I contribute imagery?

Yes. Sign in to the [uploader](https://upload.imagery.hotosm.org/) to add
georeferenced, openly licensed imagery.

If you are an imagery provider, you can also look into being ingested
into our [STAC catalog on a schedule](../dev/new-provider.md).

## How else can I contribute?

Report bugs or suggest improvements in the
[GitHub issue tracker](https://github.com/hotosm/openaerialmap/issues), or
contribute code and documentation by following the
[contribution guide](https://github.com/hotosm/openaerialmap/blob/main/CONTRIBUTING.md).

For instructions on accessing imagery from other applications, see
[Using OAM Imagery](../usage/using-imagery.md).
